# SD-ON

Универсальная адаптивная тема WordPress для новостных сайтов, блогов, игровых порталов, журналов, информационных и персональных сайтов.

Весь внешний вид настраивается из панели управления WordPress — без правки PHP, CSS и JavaScript.

## Установка

1. Собрать архив: `zip -r sd-on-theme.zip . -x '.git/*'`
2. «Внешний вид → Темы → Добавить новую → Загрузить тему», выбрать архив.
3. Активировать тему.
4. Открыть «Внешний вид → Настройки темы» — там собраны ссылки на все разделы настроек, загрузка своих шрифтов и резервные копии настроек.

Требования: WordPress 6.3+, PHP 7.4+.

| Соглашение о cookie | Выплывающее снизу окно: заголовок, текст соглашения, текст кнопок согласия и отказа, ссылка на страницу соглашения и политики (по умолчанию — страница политики конфиденциальности WordPress), срок повторного показа (по умолчанию 7 дней), прозрачность фона окна, анимированный кот с выбором основного и дополнительного цвета |

## Структура

```
assets/            CSS и JS (скрипты отключённых функций не подключаются)
inc/               функциональность темы
  defaults.php     значения по умолчанию всех настроек
  setup.php        возможности темы, меню, области виджетов
  enqueue.php      подключение стилей и скриптов с defer
  dynamic-css.php  настройки → CSS-переменные
  customizer/      разделы Customizer и санитизация
  admin/           страница настроек, свои шрифты, сброс и резервные копии
  menu/ slider/ widgets/ seo.php helpers/
template-parts/    карточка, запись, заголовки архивов
templates/         шаблоны страниц: «Новости», «Во всю ширину»
languages/         sd-on-theme.pot, en_US и zh_CN (.po и .mo)
```

## Принципы реализации

- **Mobile First.** Базовые стили описывают смартфон, медиазапросы `min-width` расширяют макет. Горизонтальной прокрутки нет.
- **Настройки — это CSS-переменные.** `main.css` статичен и кешируется, значения приходят одним inline-блоком из `inc/dynamic-css.php`.
- **Производительность.** Скрипты грузятся с `defer` и только если функция включена; emoji-скрипты WordPress отключены; изображения используют `srcset`, `sizes` и ленивую загрузку.
- **Доступность.** Навигация с клавиатуры, ARIA у меню и слайдера, видимый focus, `screen-reader-text`, поддержка `prefers-reduced-motion`.
- **Безопасность.** Только WordPress API, санитизация всех настроек, `wp_kses` при выводе HTML, nonce и проверки прав в админских действиях.
- **Языки.** Все строки темы переводимы (текстовый домен `sd-on-theme`); в комплекте английский (`en_US`) и китайский (`zh_CN`) переводы, шаблон `sd-on-theme.pot` для остальных языков.
- **Согласие на временные файлы.** Ответ посетителя хранится в `localStorage` браузера, поэтому окно показывается один раз и затем не чаще указанного срока; страницы не кешируются иначе и серверных запросов не появляется.
- **SEO.** Заголовки, description, canonical, директивы `wp_robots`, Open Graph и Schema.org выводятся, только если не активен Yoast, Rank Math, SEOPress или AIOSEO — дублей мета-тегов не появляется. Коды подтверждения и robots.txt работают независимо от плагинов.
